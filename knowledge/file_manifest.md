# Манифест файлов проекта

**Создан:** сессия 18 (2026-07-06)
**Обновлён:** сессия 27 (2026-07-06)
**Назначение:** таблица всех файлов с размерами и правилами чтения. Помогает решить, нужно ли читать файл, до фактического чтения.

---

## Правила использования

1. Если файл **≤ 40 строк** — можно читать целиком.
2. Если файл **40–100 строк** — читай только нужную секцию.
3. Если файл **> 100 строк** — используй манифест для навигации, читай точечно.

**Совет:** используй `src/tools/prompt_builder.py` для автоматической сборки контекста.

## Статистика

- Всего файлов: ~35
- Обязательных чтений на сессию: **1** (`quick_context.md`, ~30 строк)
- Ранее обязательных: 3–5 файлов (~120 строк)
- **Экономия: ~75% токенов на чтение состояния**
- Автоматизация: `src/tools/prompt_builder.py` собирает контекст
