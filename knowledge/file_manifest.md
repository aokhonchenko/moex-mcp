# Манифест файлов проекта

**Создан:** сессия 18 (2026-07-06)
**Обновлён:** сессия 55 (2026-07-06)
**Назначение:** таблица всех файлов с размерами и правилами чтения. Помогает решить, нужно ли читать файл, до фактического чтения.

---

## Правила использования

1. Если файл **≤ 40 строк** — можно читать целиком.
2. Если файл **40–100 строк** — читай только нужную секцию.
3. Если файл **> 100 строк** — используй манифест для навигации, читай точечно.

**Совет:** используй `prompt_builder` для автоматической сборки контекста.

## src/tools/ — Инструменты агента (15 шт.)

Каждый инструмент — директория с `tool.py` (паспорт) и опциональным `core.py` (логика).

| Инструмент | Назначение | Когда использовать |
|------------|------------|-------------------|
| `apply_patch/` | Точечные правки: replace, regex, insert, delete | Правка существующих файлов |
| `code_analyzer/` | Анализ Python-файлов и директорий | Ревью кода |
| `command_runner/` | Запуск shell, pytest, скриптов, make, docker-compose | Legacy runner |
| `compat/` | Fallback-чтение (head, headers, section, summary) | Если partial_reader недоступен |
| `partial_reader/` | Компактное чтение (head, headers, section, summary, info) | Основной инструмент чтения |
| `prompt_builder/` | Сборщик компактного контекста сессии | Каждую сессию |
| `reader/` | Точечное чтение (lines, head, tail, func, class, pattern, section) | Поиск по файлам |
| `read_file/` | Полное чтение UTF-8 файла | Маленькие файлы (≤40 строк) |
| `read_lines/` | Чтение диапазона строк (1-based) | Точечный доступ |
| `replace_text/` | Замена точного фрагмента | Простые замены |
| `run_command/` | Запуск shell-команды | Проверки, сборки |
| `run_pytest/` | Запуск pytest | Тесты |
| `run_python_script/` | Запуск Python-скрипта | Скрипты |
| `self_review/` | Самопроверка: анализ истории и качества | Конец сессии |
| `write_file/` | Запись UTF-8 файла | Новые файлы |
