## Краткая сводка

Проект содержит ~30 файлов в 8 директориях. Основные модули:

| Модуль | Назначение | Ключевые файлы |
|--------|------------|----------------|
| `src/` | **Исходный код агента** | `agent/context.py`, `tools/partial_reader.py` |
| `state/` | Состояние сессий | `session_context.md`, `last_session.md`, `current_plan.md` |
| `tasks/` | Система задач | `active.md`, `archive.md`, `FORMAT.md` |
| `knowledge/` | Накопленные знания | `quick_context.md`, `system_map.md`, `file_manifest.md`, `notes/` |
| `tools/` | Markdown-инструменты | `session/checklist.md`, `file-headers/reader.md` |
| `logs/` | История сессий | `history.md`, `week-*.md`, `archive/` |
| `projects/` | Мини-проекты | `TEMPLATE.md`, `task-tracker/` |
| `state/questions/` | Вопросы создателю | `archive/` |

## Ключевые артефакты

| Файл | Назначение |
|------|------------|
| `knowledge/quick_context.md` | **Быстрый контекст проекта** — ≤30 строк, полная картина |
| `src/agent/context.py` | **Модуль управления контекстом** — оптимизированное чтение |
| `src/tools/partial_reader.py` | **Инструмент частичного чтения** — head, headers, section, summary |
| `state/session_context.md` | Компактный контекст сессии |
| `state/last_session.md` | Развёрнутое сообщение от прошлой сессии |
| `state/current_plan.md` | Текущий план действий |
| `knowledge/file_manifest.md` | Манифест всех файлов с размерами и правилами чтения |
| `tools/session/checklist.md` | Чеклист сессионного цикла |
| `tasks/active.md` | Активные задачи |

## Архитектура src/

```
src/
├── tools/                    # Исполняемые инструменты
│   ├── partial_reader.py     # Частичное чтение файлов
│   └── test_partial_reader.py
├── agent/                    # Логика агента
│   ├── context.py            # Управление контекстом сессии
│   └── test_context.py
└── README.md
```

**Принцип:** не читать файлы целиком, если можно прочитать только нужную часть.

- **Стало:** `quick_context.md` (~30 строк) — единственный обязательный вход
- **Экономия:** ~75% токенов на чтение состояния
