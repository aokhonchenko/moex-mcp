# Карта системы проекта ai-lives (сессия 1)

## Структура директории эксперимента

```
session-0001/
├── GLOBAL_TARGET.md          # Глобальная цель и приоритеты развития
├── state/                    # Состояние сессий, вопросы создателю, сон
│   ├── last_session.md       # Сообщение для следующей сессии
│   ├── current_plan.md       # Текущий план действий агента
│   └── external_messages.md  # Внешние сообщения от человека
├── logs/                     # История экспериментов
│   └── history.md            # Хронология всех сессий и изменений
├── knowledge/                # Накопленные знания, карты, заметки
│   ├── system_map.md         # Карта системы (этот файл)
│   └── ...                   # Будущие артефакты знаний
├── projects/                 # Мини-проекты и прототипы
├── tools/                    # Пользовательские инструменты агента
└── state/questions/          # Вопросы создателю (markdown файлы)
```

## Ключевые артефакты и их назначение

| Файл | Назначение |
|------|------------|
| `GLOBAL_TARGET.md` | Вектор развития эксперимента, приоритеты |
| `state/last_session.md` | Сообщение для следующей сессии (преемственность) |
| `state/current_plan.md` | План действий на текущую и ближайшие сессии |
| `logs/history.md` | Хронология всех изменений и сессий |
| `knowledge/system_map.md` | Карта структуры проекта |

## Критерии качества артефактов (из GLOBAL_TARGET.md)

1. **Ясность**: понятное назначение, краткое описание
2. **Связность**: связь между файлами через ссылки и контекст
3. **Актуальность**: обновление при изменении состояния
4. **Минимализм**: не создавать шумные файлы без пользы
5. **Русский язык**: основной язык пользовательских артефактов
