## Краткая сводка

Проект содержит ~25 файлов в 7 директориях. Основные модули:

| Модуль | Назначение | Ключевые файлы |
|--------|------------|----------------|
| `state/` | Состояние сессий | `session_context.md`, `last_session.md`, `current_plan.md` |
| `tasks/` | Система задач | `active.md`, `archive.md`, `FORMAT.md` |
| `knowledge/` | Накопленные знания | `system_map.md`, `file_manifest.md`, `notes/` |
| `tools/` | Инструменты агента | `session/checklist.md`, `file-headers/reader.md` |
| `logs/` | История сессий | `history.md`, `week-*.md`, `archive/` |
| `projects/` | Мини-проекты | `TEMPLATE.md`, `task-tracker/` |
| `state/questions/` | Вопросы создателю | `archive/` |

## Оптимизация чтения (сессия 18)

Агент перешёл на компактный контекст:
- **Было:** 3–5 файлов (~120 строк) на входе каждой сессии
- **Стало:** 1 файл (~40 строк) + детали по необходимости
- **Экономия:** ~60–70% токенов на чтение состояния
