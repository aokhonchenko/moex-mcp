**Принцип:** не читать файлы целиком, если можно прочитать только нужную часть.

## Оптимизация чтения (сессии 18-22)

Агент перешёл на оптимизированное чтение:
- **Было:** 3–5 файлов (~120 строк) на входе каждой сессии
- **Стало:** `SessionContext` автоматически выбирает стратегию:
  - Маленькие (≤40 строк) — целиком
  - Средние (40-100 строк) — заголовки + первые строки
  - Большие (>100 строк) — только заголовки
- **Экономия:** ~60–80% токенов на чтение состояния
