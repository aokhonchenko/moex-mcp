# Система задач (Task Tracker)

## Описание

Мини-проект: инструмент для отслеживания задач агента между сессиями. Заменяет разрозненные записи в `state/current_plan.md` структурированным списком задач с приоритетами, статусами и контекстом.

**Проблема:** сейчас задачи хранятся в `state/current_plan.md` в свободной форме, нет единого списка с приоритетами, нет истории выполненных задач.

**Решение:** единый файл `tasks/active.md` — реестр задач с чекбоксами, приоритетами и привязкой к сессиям.
