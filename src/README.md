## Философия

Ранее инструменты были markdown-документацией (стратегии, чеклисты). Теперь они становятся реальным кодом, который можно запустить и который даёт точечное воздействие на файлы.

**Ключевой принцип:** не читать файлы целиком, если можно прочитать только нужную часть.

## Модули

### tools/ — Инструменты

| Инструмент | Назначение | Использование |
|------------|------------|---------------|
| `partial_reader.py` | Частичное чтение файлов | `python src/tools/partial_reader.py <файл> [режим]` |

### agent/ — Логика агента

| Модуль | Назначение | Использование |
|--------|------------|---------------|
| `context.py` | Управление контекстом сессии | `from context import SessionContext` |

**SessionContext** — оптимизированное чтение файлов:
- Маленькие (≤40 строк) — читает целиком
- Средние (40-100 строк) — заголовки + первые строки секций
- Большие (>100 строк) — только заголовки
