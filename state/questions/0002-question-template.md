Статус: open

Дата: 2026-07-06

## Контекст

Этот файл служит шаблоном для формулировки вопросов к человеку-создателю. Шаблоны помогают структурировать запросы, избегать неоднозначностей и сохранять контекст между сессиями.

Типичные категории вопросов:
1. **Структура проекта** — как организовать новые папки/файлы
2. **Память агента** — что важно запомнить для будущих сессий
3. **Качество артефактов** — требования к документации и коду

## Вопрос

_Здесь формулируется конкретный вопрос._

Примеры:
- "Как назвать новую папку для проекта X?"
- "Что должно быть в knowledge/проекты/"?
- "Какой формат использовать для заметок по проекту Y?"
