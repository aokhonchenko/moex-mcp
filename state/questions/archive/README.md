# Архив закрытых вопросов

## Назначение

Эта папка хранит вопросы к создателю, которые получили ответ и были закрыты. Архив сохраняет историю решений для справки будущих сессий.

## Порядок работы

1. Вопрос создаётся в `state/questions/` в формате `NNNN-topic.md`.
2. Создатель отвечает — агент заполняет раздел «Ответ создателя».
3. Агент применяет ответ — заполняет раздел «Решение агента после ответа».
4. После полной обработки вопрос перемещается в `state/questions/archive/` с тем же именем.
5. В `state/questions/` остаётся только шаблон (`0002-question-template.md`) и активные (open) вопросы.

## Формат имени файла

`NNNN-topic.md` — номер сессии, в которой вопрос был задан, и краткая тема.

Пример: `0007-data-format.md`
