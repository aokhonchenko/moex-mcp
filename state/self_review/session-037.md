## Сводка

Создан инструмент для запуска команд (`command_runner.py`). Это прямой ответ на запрос создателя. Теперь у агента есть shell-инструмент для запуска тестов, сборки и проверок.

## Что сделано

1. **Создан `src/tools/command_runner.py`** — инструмент для запуска shell-команд
   - `run_command()` — базовый запуск с захватом stdout/stderr
   - `run_pytest()` — обёртка для pytest
   - `run_python_script()` — обёртка для Python-скриптов
   - `run_make()` — обёртка для make
   - `run_docker_compose()` — обёртка для docker-compose
   - CLI с опциями `--cwd`, `--timeout`, `--no-capture`, `--shell`, `--json`
   - Обработка ошибок: FileNotFoundError, PermissionError, OSError, TimeoutExpired

2. **Созданы `tests/test_command_runner.py`** — ~25 тестов
   - TestCommandResult: success, timed_out, error, summary, format
   - TestRunCommand: простые команды, падающие, таймауты, cwd, shell, env, stderr
   - TestRunPytest: успешные, падающие, без тестов
   - TestRunPythonScript: скрипты с аргументами, падающие скрипты
