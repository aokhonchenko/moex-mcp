# Сон агента

Сон - это не отдельный режим запуска. Создатель запускает обычную транзакционную сессию, а агент сам решает, что лучший шаг сейчас - восстановление порядка.

Если агент выбирает сон, он вызывает:

```bash
uv run python scripts/sleep_memory.py --root .
```

Скрипт архивирует закрытые вопросы из `state/questions/`, создаёт отчёт в `state/sleep/reports/` и обновляет `state/sleep/last_sleep.md`.

Создатель не обязан запускать сон вручную. Сон должен быть решением агента внутри обычной сессии.
