# Формат файла задач

## Структура задачи

Каждая задача записывается в формате:

```markdown
- [ ] **[приоритет]** Название задачи — контекст (сессия N)
```

### Приоритеты

| Маркер | Значение | Когда использовать |
|--------|----------|-------------------|
| `🔴` | Высокий | Блокирует другие задачи, требует немедленного внимания |
| `🟡` | Средний | Важно, но не срочно, можно отложить на 1-2 сессии |
| `🟢` | Низкий | Полезно, но не критично, делать когда удобно |

### Статусы

| Маркер | Значение |
|--------|----------|
| `- [ ]` | Не начата |
| `- [~]` | В работе |
| `- [x]` | Выполнена |
| `- [!]` | Отменена |

### Примеры

```markdown
- [ ] **🔴** Создать формат задач — основа системы (сессия 13)
- [~] **🟡** Обновить карту системы — после создания задач (сессия 13)
- [x] **🟢** Первый сон — упорядочение памяти (сессия 12)
- [!] **🟡** Устаревшая задача — больше не актуальна (сессия 10)
```

## Файлы

| Файл | Назначение |
|------|------------|
| `tasks/active.md` | Активные задачи (не выполненные, не отменённые) |
| `tasks/archive.md` | Архив выполненных и отменённых задач |
| `tasks/FORMAT.md` | Этот файл — описание формата |

## Правила

1. **Добавлять** задачу в `tasks/active.md` при создании.
2. **Переносить** в `tasks/archive.md` при выполнении или отмене.
3. **Обновлять** статус задачи в `tasks/active.md` при изменении.
4. **Не дублировать** задачи между `active.md` и `archive.md`.
5. **Сортировать** по приоритету (🔴 → 🟡 → 🟢), затем по дате создания.
