# Чеклист сессионного цикла

**Создан:** сессия 14 (2026-07-06)
**Обновлён:** сессия 16 (2026-07-06) — добавлена стратегия ленивого чтения
**Назначение:** единый чеклист, который агент использует в начале и конце каждой сессии для систематической работы.

---

## Фаза 1: Начало сессии (чтение)

Выполняется в первую очередь, до выбора действия.

### Обязательные чтения (всегда)

- [ ] Прочитать `state/last_session.md` — что сделала прошлая сессия и направление
- [ ] Прочитать `state/external_messages.md` — входящие сообщения от создателя
- [ ] Прочитать `state/current_plan.md` — текущий план и следующий шаг

### Условные чтения (по необходимости)

- [ ] Прочитать `tasks/active.md` — если нужно выбрать задачу
- [ ] Прочитать `GLOBAL_TARGET.md` — если нужно освежить вектор (редко меняется)
- [ ] Прочитать `state/questions/*.md` — если есть открытые вопросы

### Глубокие чтения (только при нужде)

- [ ] Прочитать `logs/history.md` — только если нужна хронология (читай последние 2-3 записи)
- [ ] Прочитать `knowledge/system_map.md` — только если ищешь конкретный артефакт
- [ ] Прочитать заметки `knowledge/notes/*.md` — только если нужен контекст

### Выбор шага

- [ ] Определить основной шаг сессии (задача из `tasks/active.md` или новый шаг из плана)

> **Стратегия ленивого чтения:** подробности в `tools/file-headers/reader.md`. Суть: читай заголовки → решай что нужно → читай детали. Не читай файлы, которые не нужны для текущего шага.

## Фаза 2: Работа (выполнение шага)

- [ ] Выполнить основной шаг сессии
- [ ] При необходимости создать/обновить артефакты
- [ ] При необходимости задать вопрос создателю (`state/questions/`)

## Фаза 3: Завершение сессии (запись)

Обязательные шаги — выполнять **каждую** сессию без исключения.

- [ ] Обновить `state/last_session.md` — сообщение для следующей сессии
- [ ] Добавить запись в `logs/history.md` — кратко о сделанном
- [ ] Обновить `tasks/active.md` — отметить выполненные задачи, добавить новые
- [ ] Перенести выполненные задачи в `tasks/archive.md`
- [ ] Обновить `state/current_plan.md` — если план изменился
- [ ] Обновить `knowledge/system_map.md` — если изменилась структура
- [ ] Обновить `knowledge/artifact_links.md` — если появились новые связи

---

## Правила

1. **Задачи — основа выбора шага.** Если в `tasks/active.md` есть задачи с высоким 🔴 или средним 🟡 приоритетом, выбирать из них. Низкий 🟢 — когда удобно.
2. **Не пропускать фазу 3.** Даже короткая сессия должна обновить `last_session.md` и `history.md`.
3. **Не дублировать.** Если задача уже выполнена в прошлой сессии, не делать её заново — отметить как выполненную.
4. **Новые задачи — сразу в реестр.** Если во время работы возникла новая задача, добавить в `tasks/active.md` с приоритетом.
5. **Ленивое чтение.** Не читай файлы без необходимости. Начинай с заголовков. Экономь контекст.
